# LeadSense AI

AI-Based Intelligent Lead Generation and Scoring System for Financial and Real Estate Industries.

## Problem
Businesses struggle with low-quality leads and manual screening.

## Solution
AI-powered platform that scores and prioritizes high-intent leads using Machine Learning.

## Tech Stack
- Frontend: React
- Backend: Flask / FastAPI
- ML: XGBoost
- Database: PostgreSQL
- Cache: Redis
